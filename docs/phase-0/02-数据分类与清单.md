# 数据分类与清单

## 1. 数据分级建议

| 级别 | 定义 | 首版处理建议 | 示例 |
|---|---|---|---|
| L0 公开 | 对外公开或不涉及内部信息 | 可用于联调和功能演示 | 公开产品手册 |
| L1 内部 | 内部使用，泄露影响较低 | 优先用于试点 | 内部流程、操作规范 |
| L2 敏感 | 含客户、员工、合同或经营信息 | 脱敏后使用，严格权限过滤 | 客户资料、报价文件 |
| L3 高敏 | 核心机密、凭证、密钥或法律限制数据 | 阶段 0 不导入 | 密钥、身份证件、未公开财务数据 |

## 3. 试点样本最低要求

- 本次试点先使用 8 份 Markdown 文档；二期再补充 PDF、DOCX 各 5 份。
- 至少包含有明确章节、页码或标题结构的文档，用于验证引用。
- 先选 Docker、FastAPI、Qdrant、Ollama 共 5 份文档做版本更新和删除测试。
- 不得包含密码、API Key、访问令牌、身份证号、银行卡号等内容。
- 每份文档保留原始文件、来源路径、版本号、更新时间和责任人信息。
