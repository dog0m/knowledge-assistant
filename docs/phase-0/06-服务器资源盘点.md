# Docker 服务器资源盘点

请在目标 Docker 服务器执行下列命令，把输出粘贴到对应位置。命令只读，不会修改服务器。

## 1. 采集命令

在目标 Docker 服务器执行以下只读命令，把输出填写到对应位置。

```bash
hostname
# <填写主机名>

date -Is
# <填写时间>

uname -a
# <填写内核信息>

cat /etc/os-release
# <填写发行版>

lscpu
# CPU 型号、核心数、线程数
# <填写>

free -h
# 内存总量
# <填写>

nvidia-smi
# GPU 型号与显存（如无 GPU 可跳过）
# <填写>

docker info --format "CPUs={{.NCPU}}\nMemory={{.MemTotal}} bytes"
# <填写>
```
