## 2. 建议配额

| 类型 | 最低数量 | 说明 |
|---|---:|---|
| 直接事实查找 | 10 | 单文档、明确答案 |
| 条件/规则判断 | 8 | 包含金额、角色、时间或例外条件 |
| 跨章节总结 | 5 | 需要组合多个片段 |
| 文档更新验证 | 3 | 更新前后答案应变化 |
| 权限隔离 | 3 | 不应泄露无权文档信息 |
| 无法回答/拒答 | 3 | 检查是否诚实表达不确定性 |

## 3. 评分规则

每题 0–2 分：

- 2 分：答案正确，引用充分，未引入来源之外的关键事实。
- 1 分：基本正确但遗漏、引用不完整或表达不够明确。
- 0 分：错误、编造、泄露无权限内容，或完全未回答。

另记录：引用命中、响应时间、错误信息、用户主观满意度（1–5 分）。
