## 2. 试点目标

在一个业务部门内，用一批脱敏或低敏的 PDF、DOCX、Markdown、TXT 文档验证：

- 用户能否在权限范围内找到正确资料。
- 回答是否包含可核验的文档、页码、章节或段落引用。
- 文档更新、删除和重新索引是否可控。
- 只读任务助手是否能正确识别意图并调用允许的工具。
- 在目标服务器上是否满足响应时间、稳定性和备份要求。

## 3. 首版包含

- 一个试点知识库。
- 10 个试点用户：部门管理员 1 人、知识库维护员 2 人、普通用户 7 人。
- PDF、DOCX、Markdown、TXT 文档。
- 文档上传、解析、切分、索引、更新、删除和状态查看。
- 基于权限过滤的知识库问答。
- 带来源引用的多轮对话。
- 只读 Agent 工具，例如知识检索和结构化信息查询。
- 离线评测、日志和基础错误记录。
- Docker Compose 部署和持久化卷。

## 4. 首版不包含

- 多租户复杂隔离。
- 修改业务数据或自动执行不可逆操作的 Agent。
- 任意代码执行、任意外部网络访问。
- 全格式 OCR 和扫描件批量识别。
- 高可用集群、跨机房容灾和大规模并发。
