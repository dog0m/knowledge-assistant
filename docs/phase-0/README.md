# 阶段 0：需求与数据盘点

本目录用于阶段 0 的盘点和决策记录。`[待填写]`、`TBD` 和 `□` 表示需要补充确认的内容。

## 建议使用顺序

1. 填写 `01-范围说明.md`，明确试点部门、用户和首版边界。
2. 使用 `02-数据分类与清单.md` 登记文档，并选出脱敏或低敏样本。
3. 根据真实组织结构修改 `03-角色与权限草案.md`。
4. 让试点用户填写 `04-试点评测问题集.md`，形成固定评测集。
5. 有样本文档和服务器数据后，填写 `05-验收指标.md` 与 `06-服务器资源盘点.md`。

## 阶段 0 完成判断

- [ ] 试点部门和首版范围已经确认。
- [ ] 试点文档已登记，敏感级别和权限来源明确。
- [ ] 至少有 30 道带标准答案或评分要点的评测问题。
- [ ] 角色权限草案经过业务负责人确认。
- [ ] 服务器 CPU、内存、磁盘、GPU、Docker 和备份信息已记录。
- [ ] 首版验收阈值、负责人和测试方式已经确定。
