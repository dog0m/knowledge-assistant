# 阶段 0 验收指标

指标先作为可调整的初始阈值，拿到真实服务器和评测集后再冻结版本。

## 1. 功能与质量

| 指标 | 初始目标 | 测量方法 | 负责人 | 结果 |
|---|---|---|---|---|
| 评测集规模 | 30 题 | 检查试点评测问题集 | 项目组 | 基线已建立 |
| 答案正确率 | ≥ 80%（平均每题 ≥ 1.6 分） | 人工按 0–2 分评分 | 项目组+试点用户 | 部署后测量 |
| 引用命中率 | ≥ 85% | 引用是否支持答案 | 项目组 | 部署后测量 |
| 无依据编造率 | ≤ 5% | 拒答类和事实题抽检 | 项目组 | 部署后测量 |
| 权限隔离通过率 | 100% | 权限验收场景全通过 | 系统管理员 | 部署后测量 |
| 文档处理成功率 | ≥ 95% | 成功处理数/提交数 | 知识库维护员 | 部署后测量 |

## 2. 性能与稳定性

| 指标 | 初始目标 | 测量方法 | 结果 |
|---|---|---|---|
| 首字节响应时间 P95 | ≤ 5 秒 | 压测 5 个并发请求 | 部署后测量 |
| 完整回答时间 P95 | ≤ 15 秒 | 固定评测集重复测试 | 部署后测量 |
| API 错误率 | ≤ 2% | 测试期间统计 5xx/请求数 | 部署后测量 |
| 重启后数据保留 | 100% | 重启容器后抽查文档、会话和索引 | 部署后验证 |
| 备份恢复 | 可恢复 | 在临时环境恢复 PostgreSQL、Qdrant 和文件 | 演练后记录 |

## 3. 安全与运维

- [ ] 密钥来自环境变量或密钥管理，不写入代码和镜像。
- [ ] 原始文档、PostgreSQL、Qdrant 和日志均有明确存储路径。
- [ ] 备份包含恢复说明、时间点和校验结果。
- [ ] 关键操作和问答引用可关联到用户、时间、文档版本。
- [ ] 外部模型调用开关、数据出网边界和日志脱敏规则已确认。
